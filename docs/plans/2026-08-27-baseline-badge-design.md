# 基准列 Base 标签设计

## 目标

当比较配置指定 `baseVersionId` 时，在匹配版本列的表头版本名右侧显示紧凑的 `Base` 标签，使基准列除了背景高亮外还有明确的文本标识。

## 交互与视觉

标签只出现在表头，不显示在每个数据单元格中，也不包含计数。它沿用 Diff 标签的紧凑方块语言，但使用蓝色基准语义，避免被误解为字段差异。

未提供 `baseVersionId` 时不渲染标签，现有非比较表格外观不变。自定义基准列 className 仍只控制表头与单元格样式，不影响标签是否显示。

## 验证

组件 UI 测试覆盖：基准列有一个 `Base` 标签，未配置基准列时没有该标签。基准列高亮与综合高级配置示例继续展示该能力，源码面板由真实示例文件自动更新。
