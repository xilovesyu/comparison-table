# Difference Indicator 设计

## 默认显示

差异标识为紧凑的 `Diff` 方块。

- 直接发生变化的叶子行显示 `Diff`。
- 含差异后代的父行显示 `Diff`，并以上标展示其子树中直接变化的字段总数。
- 聚合数量不把父节点自身计入，避免对象节点和其字段重复计数。

## API

`comparison.differenceIndicator` 支持：

- `false`：隐藏标识。
- 回调：接收路径、各版本值、直接差异标记、子树直接差异数量及差异版本 ID，返回任意 React 节点。

默认行底色仅突出直接差异行；父行使用较轻的背景以表明其包含变化。

## 测试

核心测试验证直接差异和聚合数量。组件测试验证默认 `Diff` 方块与上标数量，以及自定义 React 节点替换默认标识。
