# 示例模块与完整源码面板设计

## 目标

将不断增长的 `App.tsx` 拆分为按示例组织的模块，并让每个“查看源代码”面板展示可复制的完整单文件示例：imports、版本数据、配置、状态和 JSX 都必须包含。

## 方案

每个示例放入 `src/examples/` 下独立的 `.tsx` 文件。示例模块直接声明自己的数据、规则、renderer 和交互状态，并导出其展示组件。

Vite 的 `?raw` 导入读取同一个示例文件的源文本，交给通用的 `ExampleCard` 源码面板。这样运行代码与展示代码来自同一文件，避免手写字符串遗漏版本数据或配置、也不会随着改动漂移。

`App.tsx` 只保留页面标题、全局主题及按文档顺序排列的示例组件。既有的示例顺序不变，综合高级配置仍在最后，并继续覆盖各项能力。

## 验证

保留现有的页面与组件行为测试，新增 UI 测试：打开综合高级配置的源码面板后，可看到版本数据、属性定义、比较配置和表格 JSX。执行格式检查、单元测试和生产构建。
